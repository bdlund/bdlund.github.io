# Brady D. Lund – academic site

Static site (no build step). Upload the contents of this folder to the root of the bdlund.github.io repository.

- index.html: home page
- papers/*.html: one page per paper, with Google Scholar citation_* meta tags
- pdf/*.pdf: repository PDFs (cover page + manuscript)
- data/*.csv: survey sample-size table
- assets/: style.css, site.js
- sitemap.xml, robots.txt (these replace the existing ones)

Leave annotatedbib.html, the google...html verification file, Gemfile and config.yml in the repository as they are.
Check each paper's "About this version" note against the publisher's current sharing policy.
